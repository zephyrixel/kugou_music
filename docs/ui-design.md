# UI 设计与验证

本轮以 Android 为优先，延续炭黑、暖白与琥珀视觉，通过封面氛围、开放列表与跨页面
悬浮播放器建立连续的浏览体验。主导航为“发现、搜索、我的”，桌面保留侧边导航。
实现覆盖首页、搜索、音乐库、歌单、播放器、登录、账号、会员、设置及共享弹层。
现有 Lite SDK、认证、音乐库和队列业务逻辑继续复用，数据库、生成绑定和依赖版本没有变化。

## 视觉规范

- 背景 `#101012`，普通表面 `#19191C`，浮层 `#242427`；主文字 `#F5F2EB`，次文字
  `#ABA8A2`，强调色 `#E7B36A`。错误与危险操作使用独立语义色。
- 系统字体，页面标题 28、区块标题 20、歌曲标题 16、正文 14、辅助信息 12–13。
  中文使用正常字距，以字号、字重和留白区分层级。
- 间距以 4dp 为基础；页面边距 20dp，区块间距 32dp；封面与普通控件圆角 12dp，
  弹层圆角 24dp。交互目标至少 48dp；大字号允许组件增高和换行。
- 封面保留原色与清晰度；发现页、歌单页和悬浮条使用静态封面氛围，持续背景运动仅用于
  全屏播放器。模糊背景使用受限尺寸纹理与渐变遮罩，保证文字对比度。
- 发现页以每日推荐为重点，电台为轻量入口，发现内容交替使用封面架和三行歌曲组。
  “我的”将账号入口与页面标题合并，收藏与历史入口采用紧凑横向布局。
- 歌曲列表统一主次文字、尾部菜单、当前播放／暂停标识；普通列表不使用排名色。
  点击反馈由各行的 Material 承载，避免被背景遮住。
- 对加载、空内容、失败、禁用、悬停、焦点和按压状态统一处理。状态文案说明问题与下一步，
  操作提示避免重复说明；破坏性操作保留影响说明。

## 交互与实现边界

- “我的”复用 `/library`，收藏、历史、账号与播放器的原有路由继续有效。
- 外层 `ShellRoute` 通过 `PlaybackShell` 持有一个迷你播放器，包含主导航及歌单、账号、
  设置、日志详情页。`AppShell` 只管理导航；`/player`、登录和启动页位于根 Navigator。
- 悬浮条位于底部导航或系统安全区上方，左右留白 12dp，宽屏在内容区居中且最大宽度
  760dp。封面和文字打开全屏播放器，播放与队列按钮独立响应；连续点击只打开一次。
- `PlaybackInsets` 传递实测播放条高度；列表尾部添加避让空间，内容仍可从悬浮条后滚过。
  根 Scaffold 统一处理键盘与提示消息的布局，子页面不重复缩减高度。键盘出现时收起
  播放条和底部导航，输入与播放状态保留；关闭后恢复。没有当前歌曲时，提示仍避让导航。
- 队列、音质、菜单与对话框使用根 Navigator，覆盖并阻断背后的悬浮条操作。全屏播放器
  打开后由完整界面接替，返回时回到原浏览位置；登录和启动页不展示悬浮条。
- 首页宽屏将每日推荐与电台入口并排展示；搜索在短屏隐藏重复标题，宽屏短窗口将输入与
  分类放在同一行。歌单头部自然增高，简介可展开，播放栏使用 `PinnedHeaderSliver` 自动
  适应内容高度；滚动时歌单名进入顶栏，封面背景渐隐到列表。
- 播放器展开 420ms，收起 320ms；从顶部或封面区域拖动共享路由动画进度，取消后复位。
  歌词与进度条使用各自手势区域。封面 Hero 保持单一实例，切歌过渡放在其内容内部，
  并传递转场约束、沿中心弧线插值，避免收起时骤缩或拉伸封面。
- 背景使用约 12 秒的低幅移动，只变换已保留的图层；暂停、路由不可见、后台或关闭动画时
  停止。进度、歌词高亮与播放按钮分别更新，避免位置变化带动整页重建。
- 共享组件保留在 `core/widgets`，播放器专属动效在播放器和路由模块；没有新增通用页面
  配置框架、主题切换系统或持久化 UI 状态。
- 歌词边缘渐隐，手动浏览后可返回当前行；减少动画时使用直接定位，避免把零时长传给
  滚动动画。加载、错误和空状态采用简短文案，保留重试和必要的影响说明。

## 验证记录

- `flutter analyze --no-pub`：通过。
- `flutter test --no-pub`：201 项通过。
- `flutter build apk --debug --no-pub`：通过。
- 逐页检查手机、桌面、320dp 窄屏、短横屏和 2 倍字号的渲染；重点检查布局、真实文字、
  封面、层级与状态。截图只用于人工评审，不作为锁定像素的自动化测试。
- 行为测试覆盖跨页面播放不中断、连续点击展开只产生一个播放器、返回来源页、列表末项
  可达、提示消息避让、弹层阻断、登录失效后隐藏、键盘开关与无歌曲状态。沿用播放器控制
  可达性、拖动取消／关闭、歌词与进度手势隔离及减少动画检查。
- 本轮测试只断言关键交互和相对遮挡关系，不锁定颜色、圆角、布局层级、动效时长或整页像素。
- 本机未连接 Android 设备，未完成 60/120Hz 实机帧耗时、真实手势体感及系统媒体控制验证。
  软件渲染截图与测试不能代替性能数据；没有声称取得已测量的帧率提升。
