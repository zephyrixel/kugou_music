# 使用指南

本指南描述当前已实现的使用流程。网络、登录和播放能力依赖 Lite 服务；服务端权限、
地区、账号状态或歌曲版权可能使某些内容不可用。

## 开始使用

1. 在 Android、Linux 或 Windows 安装对应发行包。平台依赖见[平台支持](platforms.md)。
2. 首次启动时，应用初始化本地数据库、音频运行时、Rust Lite SDK 和安全存储。
3. 在登录页输入手机号并请求短信验证码。发码前会登记本机设备；登记失败时可稍后在
   “我的 → 账号与会员”重试。
4. 登录成功后直接进入主界面，云端歌单和历史在后台同步。音乐库显示同步进度，失败时可点击同步按钮重试；
   同步未完成时仍可使用发现和搜索，音乐库写操作在准备完成后开放。

会话只保存在系统安全存储。更换设备、清除安全存储或会话校验失败后需要重新登录。

## 浏览与播放

主导航固定为“发现、搜索、我的”。大屏使用侧边栏，小屏使用底部导航；导航分支会
保留各自的滚动位置和搜索状态。

- **发现：** 查看每日推荐、推荐歌曲、猜你喜欢和心动电台。猜你喜欢的播放、收藏
  与不喜欢操作会按 Lite 协议记录推荐反馈。
- **搜索：** 搜索歌曲或公开歌单。搜索与公开歌单会分页面加载，播放时队列也会在接近末尾
  时继续加载下一页。
- **我的：** 浏览我喜欢、最近播放和云端歌单；顶部可进入账号详情与设置。收藏、歌单增删与编辑先更新本地界面，
  再写回服务端；写回失败会恢复本地状态并显示错误。

点击歌曲会创建带来源的播放队列。应用只在新歌曲的地址成功装载后记录最近播放，避免
因解析或网络失败产生错误历史。

## 播放器与缓存

点击底部迷你播放器可展开完整播放器。在顶部或封面区域下拉可收起，拖动距离不足时会回到
原位；也可使用左上角收起按钮或系统返回。封面与歌词支持横向切换；歌词纵向滚动和进度条
拖动不会触发页面收起。搜索键盘出现时，底部播放器与导航暂时让出空间，音乐继续播放。
播放器背景只在页面可见且正在播放时缓慢移动，暂停、切入后台或系统关闭动画后停止。


播放器支持标准、320K、FLAC、Hi-Res 和 DSD。实际可用质量由服务端资源决定，界面会显示
最终选中的质量和码率。完整资源不可用时，应用只会尝试一次同档位的免费试听；试听结束
位置由服务端返回并自动暂停。

支持四种队列模式：顺序、列表循环、单曲循环和随机。队列、当前位置和模式会随当前账号
保存；清理临时缓存不会删除队列。重启后恢复，但不会自动开始播放。退出登录会清除该账号的队列和音乐库缓存。

音频缓存采用 LRU 清理，默认上限 1 GB，可在设置中调整到 256 MB 至 8 GB。缓存清理不会
删除登录状态、音乐库或正在播放/下载的文件。缓存只识别歌曲资源与实际质量，不会保存
临时播放 URL 作为长期身份。

## 歌词、媒体控制与桌面交互

歌词优先读取本地缓存；服务端没有歌词的结果会暂存 24 小时，避免重复请求。进度条在结束
拖动时才执行 seek，减少连续网络 Range 请求。

- Android 使用通知、锁屏、耳机和蓝牙媒体控制。Android 13 及以上应允许通知权限。
- Linux 使用 MPRIS；Windows 使用 SMTC。两端均支持硬件媒体键。
- Linux 与 Windows 关闭主窗口默认隐藏到系统托盘。托盘菜单可显示窗口、播放/暂停、
  上一首、下一首或彻底退出。
- 桌面快捷键：空格播放/暂停，`Ctrl+Left`/`Ctrl+Right` 上一首/下一首，
  `Ctrl+1`/`Ctrl+2`/`Ctrl+3` 切换主导航。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 启动后要求重新登录 | 会话可能过期或与设备身份不匹配。重新获取验证码即可；不要尝试导入其他设备的会话。 |
| 登录后音乐库仍在加载 | 同步在后台进行，可先使用发现和搜索；同步失败时点击同步按钮重试。 |
| 某首歌不可播放 | 资源可能受权限、版权或网络限制。尝试其他质量，或等待免费试听降级结果。 |
| 桌面关闭后找不到窗口 | 从系统托盘图标选择 Show KGMusic，或使用托盘菜单彻底退出后重新启动。 |
| Linux 无法保存登录 | 安装并启动桌面环境的 Secret Service 凭据服务。 |
| 需要诊断信息 | 优先使用普通日志；仅在必要时临时启用 Trace。Trace 可能包含完整网络数据，导出前必须复核，完成后切回较低等级并清空；详见[安全与隐私](security.md)。 |

## 当前限制

应用不提供离线编辑队列、离线搜索、Standard 后端、iOS、macOS 或 Web 发布支持。SDK 尚未
稳定或未暴露的 Lite 能力不会以假数据形式展示。
